## O que é?
Projeto Customs é um terminal java que permite a customização de um 4 modelos de carro unicos com uma variedade de opções, envolvendo opções exclusivas apenas para alguns modelos. Ao acabar, há uma opção para revisar todas as opções, junto do preço de todas as escolhas feitas pelo usuário.

## Como funciona?

Feito inteiramente em lista, o usuário apenas deve seguir as instruções ditas e escolher as opções que forem de seu agrado usando o número da opção ou escrevendo o que deseja, terminando em um resumo que mostra o preço e as escolhas.

## Objetivo

O objetivo desse projeto é criar um sistema entuítivo de escolha para o usuário que o entregue um produto pronto e customizado inteiramente por ele.
